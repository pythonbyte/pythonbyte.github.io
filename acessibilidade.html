Acessibilidade

Práticas adotadas neste site institucional e como reportar problemas.

Compromisso

Este site institucional da PYTHONBYTE SOFTWARE SERVICES LTDA foi elaborado com o objetivo de ser utilizável pelo maior número possível de pessoas, inclusive com o uso de teclado, leitores de tela e sem JavaScript. As práticas abaixo são orientadas pelas diretrizes WCAG (Web Content Accessibility Guidelines). Esta página não constitui certificação formal de conformidade.

Práticas adotadas neste site

  • Idioma da página declarado em português do Brasil.
  • Marcação HTML semântica, com regiões como cabeçalho, navegação, conteúdo principal e rodapé.
  • Link para pular direto ao conteúdo principal.
  • Hierarquia de títulos e contraste entre texto e fundo pensados para leitura.
  • Indicador de foco visível nos links e demais elementos interativos.
  • Layout responsivo, para uso em telas estreitas e amplas.
  • Funcionamento sem JavaScript e sem dependência de fontes ou scripts externos.
  • Textos alternativos em imagens que transmitem informação, quando houver.

Como reportar uma barreira

Se encontrar alguma dificuldade para usar este site, escreva para eduardommelgaco@gmail.com, descrevendo a página, o recurso utilizado e o problema observado.
